# Excel Sales Dashboard Project

An interactive **Sales Dashboard built using Microsoft Excel** to analyze sales data, track key performance indicators (KPIs), and visualize business performance.

## Features
- Sales performance analysis
- KPI tracking
- Interactive charts and graphs
- Sales trend visualization
- Data summarization using PivotTables
- Insights to support data-driven decision-making

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel Formulas
- Data Cleaning
- Data Visualization

## Objective
To transform raw sales data into meaningful insights using Excel and develop practical skills in data analysis and business intelligence.

## Project Outcome
This project demonstrates the use of Excel for analyzing sales performance, identifying trends, and presenting data through an interactive dashboard.
